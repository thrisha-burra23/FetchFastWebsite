# 🚚 FetchFast - Static Website

FetchFast is a **static delivery and logistics service website** built using **HTML & CSS**.  
It provides a simple, fast, and clean user interface where users can **explore services, register, login, book deliveries, and contact support**.
live link: https://thrisha-burra23.github.io/FetchFastWebsite

## ✨ Features

- **Responsive Header & Navigation**  
  Fixed navigation bar with quick access to Home, Services, About, and Contact.

- **Landing Page (index.html)**  
  - Hero section introducing **FetchFast**.  
  - "Our Services" cards showcasing delivery features.  
  - FAQ section with common customer queries.  
  - Footer with company links & social media.

- **User Authentication (Static)**  
  - `register.html` → User registration form.  
  - `login.html` → Simple login form (redirects to Home).  

- **Booking System**  
  - `book.html` provides a **delivery booking form** (pickup/drop addresses, load type, date).  
  - Currently static (no backend integration).

- **Contact Page**  
  - `contact.html` has a form for customers to submit queries.

- **About Page** 
   - `about.html` gives information about the fetchFast 

---

## 🚀 How to Run

Since it’s a **static site**, you only need a browser:

1. Clone or download the project.
2. Open `index.html` in any browser.
3. Navigate using the header links.

## 🛠️ Tech Stack

- **HTML5** – Structure of the pages.  
- **CSS3** – Styling, layout, and responsiveness.  
- **No backend** – This project is frontend-only.
